# 🔫 簡易射擊遊戲

一個基於 Node.js + Canvas 的網頁射擊遊戲，在一分半鐘內瞄準並射擊目標來獲得最高分數！

---

## 🎮 遊戲特色

- **四種目標**：軍人（+10 分）、平民（-30 分）、坦克（+50 分）、機器怪物（+100 分）
- **隱藏 BOSS**：擊中 10 個軍人 **或** 5 個坦克時，會解鎖機器怪物目標
- **一分半鐘限時**：在時間內盡量獲得高分
- **動態生成**：目標會移動並隨機出現
- **排行榜系統**：遊戲結束自動上傳分數，顯示全體排名
- **粒子特效**：擊中目標時有爆炸粒子效果
- **星空背景**：動態閃爍的星空背景

---

## 📋 遊戲規則

| 目標 | 圖示 | 分數 | 說明 |
|------|------|------|------|
| 🪖 軍人 | 綠色 | **+10** | 普通目標，隨機生成 |
| 👤 平民 | 紅色 | **-30** | 誤傷平民會扣分！隨機生成 |
| 🎨 坦克 | 棕色繪製 | **+50** | 大型目標，隨機生成 |
| 👾 機器怪物 | 紫色 | **+100** | BOSS 目標，需解鎖後生成 |

### 機器怪物解鎖條件
- 擊中 **15 個軍人目標** 且 **5 個坦克目標**
- 兩者皆達成後，機器怪物將有機率生成

## 🚀 執行方式

### 前置需求
- [Node.js](https://nodejs.org/) v16 或更高版本

### 安裝與執行

```bash
# 1. 進入專案目錄
cd 期中專案

# 2. 安裝相依套件
npm install

# 3. 啟動伺服器
npm start

# 4. 開啟瀏覽器
# 訪問 http://localhost:3000
```

### 執行測試

```bash
npm test
```
