# 網頁設計課程作業 平時作業總結與整理
---

## 作業目錄

### [`_wp/homework/01`](./_wp/homework/01) — HTML 個人介紹頁面
- **myweb.html**：使用 CSS 個人風格首頁，包含自我介紹、技能列表、專案經驗與聯絡資訊。

### [`_wp/homework/02`](./_wp/homework/02) — HTML 問卷表單
- **02.html**：顧客滿意度問卷，包含文字輸入、下拉選單、單選/多選按鈕、文字區域與提交/重設按鈕。

### [`_wp/homework/03`](./_wp/homework/03) — Node.js 入門
- **hello.js**：第一個 Node.js 程式，輸出 `hello 你好`。

### [`_wp/homework/04`](./_wp/homework/04) — JavaScript 基礎練習（10 題）
涵蓋陣列、物件、JSON、迴圈、條件判斷、函式等基礎語法練習：
1. 陣列總和計算
2. 篩選及格學生
3. While 尋找目標數字
4. JSON 資料解析與更新
5. 庫存檢查與扣除
6. 階乘計算（while）
7. 物件轉陣列
8. 解析 JSON 並篩選便宜商品
9. 計算頻率
10. 企業部門薪資統整（綜合應用）

### [`_wp/homework/05 opencode`](./_wp/homework/05%20opencode) — 部落格系統（Express + SQLite）

| 版本 | 說明 |
|------|------|
| **blog/** | 基本版部落格 CRUD，使用 Express + sql.js |
| **blognew/** | 增強版，加入搜尋、分頁、標籤系統、文章編輯（PUT） |

### [`_wp/homework/06`](./_wp/homework/06) — JavaScript 進階練習（10 題）
1. 回呼函式（callback）
2. IIFE 與變數作用域
3. `map()` 與箭頭函式（折扣計算）
4. 陣列操作 `pop()` / `unshift()`
5. 閉包（closure）：`multiplier` 工廠函式
6. 自訂 `myFilter` 實作
7. `filter()` 篩選成年人
8. 傳值 vs 傳參照（Call by Sharing）
9. `setTimeout` 非同步
10. `reduce()` 加總 + 回呼折扣

### [`_wp/homework/07`](./_wp/homework/07) — JavaScript 實戰練習（10 題）
1. 物件點符號與中括號存取
2. 解構賦值
3. `forEach` 產生 HTML 字串
4. 動態新增物件屬性
5.  callback pattern 模擬非同步
6. JSON 解析與巢狀存取
7. 模擬資料庫查詢 callback
8. 短路求值（`\|\|`）預設值
9. `map()` 字串截斷
10. 錯誤優先 callback 模式

### [`_wp/homework/期中專案`](./_wp/homework/期中專案) — 射擊遊戲（Node.js + Canvas）
- **特色**：90 秒限時射擊，四種目標（軍人 +10、平民 -30、坦克 +50、機器怪物 +100），隱藏 BOSS 解鎖機制，排行榜系統，粒子特效與星空背景。
- **技術**：Express 伺服器、HTML5 Canvas、JSON 檔案排行榜
- **執行**：`npm install` → `npm start` → `http://localhost:3000`
